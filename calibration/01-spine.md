# Phase 1 — Spine  (DRAFT — pending author ratification)

The spine gates every phase after it. Three rulings: **scope**, **apex**, **authority**. Plus the layering consequence.

---

## 1. Scope

**Domain: the structure "a finite actor pursuing a stated outcome" — wherever it appears.**

Not defined by *who* acts (substrate-free). Defined by two gates, both required:

1. **Outcome-driven** — the effort serves a stated end. *Firewall against "universal":* undirected / non-teleological reality is out. "Not everything needs outcome-driven."
2. **Finite actor** — a bounded locus of attention holds the goal. Finitude has two faces: bounded **attention** (must focus + divide) and bounded **knowledge/reach** (must leverage beyond self).

The actor is any instance of that structure:

- a whole person (life direction)
- a slice of a person — a career, a personal project, self-management of one's own affairs
- a single mind dividing its own concerns (**SoC is intra-personal**: different internal problems → different concerns → isolate / bound for clarity)
- an AI agent
- a team / org

**Leverage = reach beyond the self by *any* external means** — tools, the internet, information, other people, AI. Delegation to another actor is *one kind* of leverage, not its definition. "I don't know everything, therefore I can leverage everything" — "everything" = the whole external world as resource.

### Noun rule (replaces "frame-neutral across all reality")

> A noun is canon-legal iff it survives across every instance: a person's personal goals ⇄ a career ⇄ an AI agent ⇄ a team.

- **Legal (structure-level):** actor, attention, goal / outcome, concern, context, leverage, boundary, truth, cost.
- **Forbidden (substrate-bound → projection):** LLM, token, context-window, subagent, code, function, ticket, KPI, headcount. Also "delegate to a human/agent" *as the definition of leverage* — too narrow; leverage spans tools + info + actors.

Canon speaks of the **actor** generically; "agent / person / team / career" are *instances*, named only in projections. This is **broader** than the old draft (admits intra-personal work + tool-leverage) yet still firewalled from "universal" by gate 1.

## 2. Apex (the resource)

**Attention — the finite, volatile *fuel* an actor burns, in iterative motion, toward an outcome-*anchor*. The whole discipline is burning it well.**

The economics that makes it tangible:

| Role | Element | Motion? |
|---|---|---|
| **Anchor** — what holds direction | Outcome / goal — without it, motion is drift, not progress | — |
| **Fuel** — what's burned for motion | **Attention** — burned, divided, conserved, extended | ✅ the protagonist |
| **Constraints** — why discipline is needed | Finite (bounded fuel) + Volatile (store clears on reset) — *properties*, not nodes | ❌ static premises |

Finitude is the adjective, not the noun: motionless, it only makes the fuel scarce — which is *why* the discipline exists. Name the apex for the thing in motion: the fuel, burning.

**Two properties of the fuel** — premises (facts about the resource), not rules, not nodes. Orthogonal: a store can be small-but-persistent or large-but-volatile, so neither implies the other.

- **Finite** — bounded *quantity*. Necessitates the *spend*-discipline (Aim / Divide / Extend).
- **Volatile by default** — the working store clears on a context reset. So the loop's learning must land in the durable truth-store (**SSOT**) before the reset wipes it; a cold start then reconstructs from SSOT alone.

Canon states the volatile/durable duality frame-neutrally; projections name the tiers (context↔files, head↔notes). The line is drawn per frame by Boundary — see `03-set.md` Finding 3.

**One property of the burn — Irreversible.** Every burn leaves a *footprint*: the realized outcome plus its side-effects, which can't be un-left and so must be owned. Footprint *is* the outcome — Outcome-Driven is its intended front, **SSOT** its recorded back. Both positive and negative trace feed back to SSOT (routed by **SoC** to the owning concern), are *contained* within bounds by **Boundary**, and a wrong one is healed on the next loop. So there is no separate "Footprint"/"Entropy" axiom: the *fact* is this property; the *handling* is Outcome + SSOT + SoC + Boundary + the loop.

**The burn is iterative, not a single payment.** Fuel moves in a loop — **decision → action → result → learning → decision** — always in motion. The path A→B (unknown→known) is rarely straight; each sprint recalibrates from real results (Grounding) while held to the anchor (Outcome). This dynamic *is* the apex in motion — which is why there is **no separate "fail-fast" or "probe" node**: fast real-action-then-recalibrate is *how the fuel burns*, not an add-on rule. ("Fail-fast" spotlit only the stop-case of this loop; anchor-less motion is the drift the loop exists to prevent.)

**Two properties of the currency** — premises (facts about the resource), not rules, not nodes. Orthogonal: a store can be small-but-persistent or large-but-volatile, so neither implies the other.

- **Finite** — bounded *quantity*. Necessitates the *spend*-discipline (Aim / Divide / Extend / Conserve).
- **Volatile by default** — the working store clears on a context reset; persistence requires a durable store. Necessitates the *persistence* corollary (externalize before the reset wipes it).

Canon states the duality frame-neutrally (**volatile / durable**); projections name the tiers (context↔files, head↔notes). The line is drawn per frame by Boundary — see `03-set.md` Finding 3.

Voiced as two **spend-strategies** (the two mottos, canon-native — both "attention" and "leverage" are structure-level under §1):

- inward — **"attention is all you need"** — concentrate your own attention on what only you can do (focus / SoC / atomic).
- outward — **"I don't know everything, therefore I can leverage everything"** — route the rest to external resources (tools, internet, people, AI). Leverage is attention-*conservation*: spend a little to acquire capability instead of a lot to do/learn it yourself.

**Why "all you need" is literal:** every other resource — knowledge, tools, others' time — is acquired by spending attention to reach it. Attention is the root currency that buys all leverage; finitude is just the fact that the wallet isn't infinite.

## 3. Authority model

**Flat stipulation, with a teleological apex. Necessity ≠ justification.**

- Each axiom is **independently stipulated** — authority comes from the posit + adoption, not from the apex, not from mutual fit. Flat rank in *authority* is unchanged from the old SEED.
- The apex is **subject + premise, not justification.** Attention's *finitude* necessitates the set — remove the constraint (infinite attention) and every axiom becomes unnecessary (you'd never need to focus, divide, conserve, target, or leverage). But the constraint *necessitates*; it does not *justify*. Each axiom's authority is still its own stipulation, not derived from attention (deriving it would be foundationalism — the old "Axiom 0" the SEED rightly forbade).

So the apparent contradiction (apex vs flat-rank) dissolves: the set is **flat in authority, rooted in purpose** — the purpose being *spend finite attention well*. This is the amendment Phase 6 writes into the First Principle — separating the *authority axis* (flat, stipulated) from the *necessity axis* (rooted in attention's finitude).

## 4. Layering consequence (locks downstream)

- **Canon** = substrate-neutral agency under finitude toward an outcome.
- **Projection** = a specific substrate. The Claude-Code lore (`~/.claude/guidelines/axiom-principles/`) is the **AI-agent** projection. A team playbook would be the **human-org** projection.
- **Phase 4 downstream gate** therefore tests: does every AI-projection lore file trace up to a canon axiom (substrate-stripped), and does every canon axiom project down into the AI frame? Substrate-bound lore content that *can't* strip to agent-neutral is correctly projection-only — not a canon gap.

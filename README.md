# axioms-protocol

The canonical, substrate-neutral axioms of **finite-actor agency** — an upstream anchor that downstream consumers project into their own frame (code, agents, planning, life).

**The canon → [`axioms/index.md`](axioms/index.md)** — self-complete: apex · scope · the seven axioms · the constitution that keeps the set closed.

Frame-specific examples and applications live in the consumer's repo, never here.

---

*Maintenance.* The canon is the single source of truth; it obeys its own axioms. Source material (drafts, notes, prior conversations) is distilled into the canon, verified, then deleted — nothing load-bearing lost. Versioning is git history until a consumer needs to pin.

# Axioms

A closed, substrate-neutral canon of finite-actor agency — and a lens to hold your work against it.

- [`AXIOMS.md`](AXIOMS.md) — the canon: apex, fuel, scope, and the seven axioms.
- `/axioms:axiom-lens <target>` — load the canon and audit a topic, design, or decision against it. Surfaces grounded concerns, possible antipatterns, and insights; proposes options. You judge.

## Install

```
/plugin marketplace add RockyHong/axioms-protocol
/plugin install axioms@axioms-protocol
```

# axioms-protocol

The canonical, substrate-neutral axioms of **finite-actor agency** — an upstream anchor that downstream consumers project into their own frame (code, agents, planning, life).

**The canon → [`AXIOMS.md`](AXIOMS.md)** — the law itself: apex · fuel · scope · authority · the seven axioms · corollaries.

**Its governance → [`CONSTITUTION.md`](CONSTITUTION.md)** — admission, hygiene, dogfood, amendment: the rules that keep the set closed and clean. Different consumer (the maintainer), different home.

Frame-specific examples and applications live in the consumer's repo, never here.

---

*Maintenance.* Governance rules live in [`CONSTITUTION.md`](CONSTITUTION.md). Working practice: source material (drafts, notes, prior conversations) is distilled into the canon, verified, then deleted — nothing load-bearing lost. Versioning is git history until a consumer needs to pin.
